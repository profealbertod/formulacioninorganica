# Formulación · Química inorgánica

Aplicación educativa en español para consultar la tabla periódica y practicar formulación y nomenclatura inorgánica.

## Funcionalidades

- Tabla periódica interactiva con búsqueda, filtro por familias y fichas de elementos.
- Ejercicios autocorregibles de óxidos, hidruros, sales binarias, hidróxidos y oxoácidos.
- Pistas opcionales y explicaciones paso a paso después de responder.
- Puntuación y seguimiento del progreso durante la sesión.
- Guía de formulación con reglas básicas y ejemplos.
- Diseño adaptable a móvil, tableta y ordenador.
- Identidad visual corporativa basada en granate, beige cálido, marfil y dorado suave.
- Sin dependencias externas ni proceso de compilación: es una web estática.

## Ejecutar localmente

Abre `index.html` en un navegador moderno. También puedes servir la carpeta con cualquier servidor estático.

## Publicar con GitHub Pages

1. Entra en **Settings → Pages** del repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama principal y la carpeta **/(root)** y guarda.
4. Cuando finalice el despliegue, GitHub mostrará la URL pública de la aplicación en esa misma sección.

## Contenido didáctico

Los números de oxidación son valores habituales orientativos y pueden tener excepciones. Conviene adaptar los nombres aceptados y el nivel de nomenclatura al currículo trabajado en clase. La puntuación se mantiene solo durante la sesión actual del navegador.
